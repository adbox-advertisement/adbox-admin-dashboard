# School card illustrations

Five playful 3D school-inspired dioramas generated with the built-in `image_gen` tool.
These are imaginative illustrations, not photographs or exact campus models.
The card assets are locally bundled 960 × 640 JPEGs.

| Asset | Inspiration |
| --- | --- |
| `ug.jpg` | Terracotta roofs, cream buildings, clock tower, floating books |
| `knust.jpg` | Yellow-trimmed campus, golden eagle, molecules and gears |
| `uds.jpg` | Green entrance, savannah trees, seedlings and gardens |
| `gh-media.jpg` | Purple-accented studio, movie camera, microphone and headphones |
| `umat.jpg` | Green campus, mineral crystals, mining helmet and miniature truck |

The full final prompt set is saved in [prompts.json](./prompts.json).
UG was generated first and used as the style reference for the remaining four assets.
The generated art replaces the previous web-sourced photos.
